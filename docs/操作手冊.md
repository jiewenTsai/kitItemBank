## 1. 開始之前：兩個版本、去哪裡打開

目前線上同時有兩個版本。平常用 **0.3**。

| | 0.3（現行） | 0.2（舊版，只修錯） |
|---|---|---|
| 網址 | <https://jiewentsai-kititembank.share.connect.posit.cloud/> | <https://01a1981a-700b-e470-a554-3b8cc7de9331.share.connect.posit.cloud/> |
| 波次怎麼寫 | 施測代號，例如 `M36M084G01`，旁邊有白話說明 | 舊代碼，例如 `M036大`、`M048小` |
| 改題庫 | 下載「修改包」→「審核」→ 交給技術人員 | 下載整份題庫 Excel |
| 什麼時候用 | 要知道「哪一次施測、哪個資料檔真的有這題」、要 codebook 或 SPSS 標籤、要維護題庫 | 只想用舊代碼查題目 |

### 雲端版和本機版

0.3 有兩種開法，畫面和十個分頁都一樣：

- **雲端版**：上面的網址，用瀏覽器打開就好。最方便。
- **本機版**：在你自己的電腦上執行。Windows 雙擊桌面的 `run.bat`；沒有的話，請技術人員幫你裝好、打開。
  打開後瀏覽器會自動出現同樣的畫面。

兩者只差在會碰到**原始資料檔（.sav）**的地方：完整的 .sav 有每個人的回答，不能傳上雲端。

| 要做的事 | 用哪一版 |
|---|---|
| 查詢（題項查詢、構面查詢、施測、比較） | 都可以，雲端版最方便 |
| 待辦事項、題庫編修、改版、審核 | 都可以，雲端版最方便 |
| 併入新施測 | 手上是 .sav → **本機版**（只讀表頭）；技術人員給你 `_meta.csv` → 雲端版 |
| 統計 | **只有本機版** |

怎麼確認版本：看畫面最上面的版本行（例如「kitItemBank v0.3.7 · …」）和題庫列的「內建題庫 2026-11-02-v3」。
本機版要跟著雲端版更新（見第 4.3 節）；兩邊的「內建題庫」版本應該一樣。

**一個重要原則**：這個 app 不會改任何檔案。你在 app 裡做的改動，只存在你這個瀏覽器分頁裡。
要真正改題庫，一律走這條路：

```
修改包（Excel）→「審核」頁檢查 → 下載套用後的題庫（zip）→ 交給技術人員 → 雲端重新部署
```

## 2. 畫面怎麼看

由上往下：

1. **頁首**：「KIT 題庫管理工具」，下面一行是版本，例如「kitItemBank v0.3.7 · 2026-11-02」。
2. **分頁列**，分三組：
   - 「查詢」：「題項查詢」「構面查詢」「施測」「比較」——只看不改。
   - 「維護」：「待辦事項」「題庫編修」「改版」「併入新施測」「審核」「統計」。
   - 「說明」：「操作手冊」——就是這本手冊，左邊是目錄；上面的「在新分頁開」可以單獨開一頁，方便列印。
3. **題庫列**（每一頁都有）：
   - 「題庫」：選「家長」「兒童青少年」「教保人員」。
   - 後面寫現在用的題庫，例如「內建題庫 2026-11-02-v3 · 2,061 題 · 24 個波次 · 198 個構面」。
   - 如果你在「題庫編修」改了東西還沒下載，會多一句「有 1 處改動還沒下載（在「題庫編修」下載）」。
   - 「打開題庫 Excel…」：打開 0.2 格式的題庫檔。一般用不到。
4. **「這一頁做什麼」**：每一頁最上面都有一段說明和步驟。忘了怎麼用時先看這裡。
5. 頁面最下面常有可以點開的小標題，例如「用 R 怎麼做」。那是給技術人員的，可以不管。

**網址可以分享**：在「題項查詢」設好條件後，瀏覽器網址列的網址就記著這些條件。
把網址貼給同事，他打開就看到同樣的查詢。

**用語提醒**（第 7 節有完整解釋）：
- 「構面查詢」頁和「題項查詢」的「構面」選單裡說的「構面」，就是題庫裡的**題組**（例如「利社會行為」）。
- 「題項查詢」表格的 `block` 欄、進階設定裡的「區塊」選單、題目細節的「區塊」，是問卷的**區塊**（例如「家庭問卷資料_親職參與」），不是上面那種題組。

## 3. 任務一：老師要「社會能力」各波次的題目

**情境**：老師說「請給我家長問卷『社會能力』在各波次的題目」。

### 3.1 先弄清楚「社會能力」在題庫裡叫什麼

題庫裡有好幾個跟社會能力有關的題組，而且分家長、兒童青少年、教保人員三個題庫。
「社會能力」本身是**上層題組**，題目都掛在它下面的**子題組**，它自己是 **0 題**。
在「構面查詢」選「社會能力」，會看到一行「這個題組本身沒有題目，題目都在它的子題組裡。點一個子題組看它的題目：主動性、合群性……」，
點子題組的名字就換到那個子題組。

家長題庫（2026-11-02-v1）裡，「社會能力」底下的子題組：

| 子題組（構面） | 題數 | 出現的波次數 | 最近一波 |
|---|---|---|---|
| 主動性 | 9 | 18 | M03M108G03 |
| 合群性 | 6 | 18 | M03M108G03 |
| 順從性 | 4 | 18 | M03M108G03 |
| 獨立性 | 4 | 13 | M03M108G03 |
| 利社會行為 | 6 | 24 | M36M156G07 |
| 同理 | 3 | 11 | M36M156G07 |
| 自我控制 | 5 | 10 | M36M144G06 |
| 遵守規範 | 4 | 18 | M03M108G03 |

（數字和「構面查詢」的構面清單一樣；題庫更新後會變。）

其他題庫：
- **兒童青少年**：「社會能力」（0 題，上層）→「社會能力_利社會行為」（4 題）、「社會能力_自我控制」（4 題）。
  另有「社會適應」系列（同儕關係、學校關係、家人關係、班級關係），那是不同的概念。
- **教保人員**：「社會能力」（0 題，上層）→「主動性」「利社會行為」「自我控制」等。

不要選錯的相似名稱：
- 「社會情緒」：更上一層（「社會能力」掛在它下面），0 題。
- 「社會情緒相關題目」：0 題。
- 「社會期許題」：測的是「回答時想表現得好」的傾向，不是社會能力。

**怎麼挑**：
1. 先問老師是哪一個題庫（家長填的、孩子自己填的、還是老師填的）。
2. 問老師要哪幾個子題組，或是全部。不確定就全部給。
3. 學前和國小的子題組名稱不同。例如家長題庫的「合群性」在國小 1–3 年級改名為「利社會行為」，
   「順從性」改名為「遵守規範」（從 M36M084G01 開始）。要跨學前、國小比較時，兩個都要給。
   這個在「構面查詢」頁會寫在「題組沿革」裡。

### 3.2 主要做法：選上層題組「社會能力」，一次下載全部子題組

1. 題庫列的「題庫」選「家長」。
2. 點分頁「構面查詢」。
   - 你會看到：右邊是「構面清單（225 個）」，欄位有「構面」「別名」「題數」「版本數」「出現的波次」「最近一波」「有信度的波次」。
3. 在左邊「構面」的搜尋框打「社會能力」，從下拉選單選「社會能力」。
   - 你會看到「這個題組本身沒有題目，題目都在它的子題組裡。點一個子題組看它的題目：主動性、合群性……」。
4. 按「下載各波次題目表（Excel）」。
   - 你會得到「題組各波次題目_社會能力.xlsx」，兩張工作表：
     - 「說明」：題組、題庫、題庫版本、產生日期，並列出包含哪些子題組
       （主動性、合群性、順從性、獨立性、利社會行為、同理、自我控制、遵守規範）。
     - 「題目」：53 列，一列是一個題目版本。第一欄「子題組」寫這一題屬於哪個子題組，
       接著是 itemID（題號）、itemVer（版本）、deprecated（停用）、respondent（填答者）、label（題目文字），
       後面每一欄是一次施測，例如「M36M084G01 · 84 個月・小一（M36 世代）」，✓ 表示那一版在那次施測有問。
       `deprecated = 1` 是已經不用的舊版本。
   - 例子：`socD09` 有兩版。第 1 版「孩子會做一些讓別人感到開心或覺得溫暖的事情。」用在國小一到三年級；
     第 2 版「這孩子會做一些……」用在小四以後。
5. 把這個檔寄給老師。老師只要其中幾個子題組，在 Excel 用「子題組」欄篩選即可。

### 3.3 只要一個子題組時

1. 在「構面查詢」選子題組，例如打「利社會」選「利社會行為」；或在「社會能力」那一頁直接點子題組的名字。
   - 你會看到標題「「利社會行為」：6 題（10 個版本）· 出現在 24 個波次 · 最近一波 M36M156G07」，
     下面是題目 × 波次的表，✓ 表示那一題在那一波有問。
2. 按「下載各波次題目表（Excel）」，得到「題組各波次題目_利社會行為.xlsx」（沒有「子題組」欄，其他一樣）。
3. 按「回到構面清單」可以換別的題組。
4. 頁面中間可以點開「題組沿革（N 筆）」，看這個題組在不同題本之間有沒有改名。
   例如「合群性」（P-36-72）→改名→「利社會行為」（P-G1-G3），從 M36M084G01 開始。

### 3.4 （需要時）產生構面報告

構面報告是一份 Word 或 HTML，一次只做**一個波次**。

1. 在「構面查詢」選好一個構面（例如「利社會行為」）。
2. 在左邊「波次（構面報告用）」選一個波次，例如「M36M084G01 · 84 個月・小一（M36 世代）…」。
3. 按「產生構面報告」。
   - 你會看到狀態框，例如「「利社會行為」在 M36M084G01 的構面報告：N 題。」
     如果寫「這個構面在這個波次沒有信度」，表示題庫還沒記信度，報告照樣可以下載。
4. 按「下載 Word」或「下載 HTML」。檔名像「構面報告_家長_M36M084G01_利社會行為_20261102.docx」。

小技巧：沒有選構面、只選波次，按「產生構面報告」，會做那個波次的**全部**構面。

### 3.5 也可以用「題項查詢」一次列出好幾個子題組

1. 點分頁「題項查詢」，題庫選「家長」。
2. 左邊「構面」選單，一個一個選：「主動性」「合群性」「順從性」「獨立性」「利社會行為」「同理」「自我控制」「遵守規範」。
3. 下面的選項保持「任一構面」（只要屬於其中一個就列出）。
4. 要限定波次，在「波次」選單選（例如打「84M」或「小一」就會找到 84 月齡的施測）；不選就是全部。
5. 右邊會寫「共 N 題……」，表格列出題目。點一列，下面出現這一題的細節（各版本、出現的波次、屬於哪些構面）。
6. 按「下載查詢結果」，得到「題項查詢_家長_日期.xlsx」，裡面有符合的題目和跨波次對照表。
7. 這時候網址列的網址記著你的條件，可以直接貼給老師。

> 已停用（舊版本）的題目預設不列。要列出來，打開「進階設定（區塊、題型、填答者）」，勾「包含已停用的題目」。

## 4. 任務二：改一個錯字，從送出到核准

**情境**：有人發現家長題目 `fatherinvo01n`（孩子父親的親職參與第 1 題）的文字結尾少了句號：

- 現在：「孩子父親的親職參與：照顧這孩子的衣、食、健康等生活基本需求」
- 應該：「孩子父親的親職參與：照顧這孩子的衣、食、健康等生活基本需求。」

（同一題的舊題號 `fatherinvo01` 第 3 版是有句號的。）

整個流程分兩個角色。可以是同一個人做，但最好由另一個人審核。

### 4.1 送出的人：在「題庫編修」改，下載修改包

1. 題庫選「家長」。
2. 點「題項查詢」，在「關鍵字」打 `fatherinvo01*`（題號開頭加 `*`）。
   - 你會看到「共 2 題（不含 2 題已停用）」：`fatherinvo01`（第 3 版）和 `fatherinvo01n`（第 1 版）。
3. 點 `fatherinvo01n` 那一列。下面出現「這一題：fatherinvo01n（第 1 版）」。
   - 可以看到「出現的波次（1 個波次）：M36M084G01 · 84 個月・小一（M36 世代）」。
4. 點「改這一題 →」。
   - 會跳到「題庫編修」，「要改什麼」已經選好「題目內容」，下面的表單帶入了 `fatherinvo01n` 第 1 版。
   - 你也可以自己點「題庫編修」→「要改什麼」選「題目內容」→「題目（itemID）」打 `fatherinvo01n`，
     再在「版本」選「第 1 版」。一題有好幾版時，一定要選對要改的那一版。
5. 在「題目文字（label）」框，在句子最後加上「。」。
6. 按「套用這一題的改動」。
   - 右上會跳出「已套用 fatherinvo01n 第 1 版的改動：題目文字。」
   - 下面出現「本次改動：題目內容 1 題 1 處」，題庫列也會寫「有 1 處改動還沒下載」。
   - 沒按「套用這一題的改動」就不會記下來。
7. 按「下載修改包」。
   - 檔名像「KIT_parent_2026-11-02_修改包.xlsx」（parent = 家長，child_adolescent = 兒童青少年，childcare_teacher = 教保人員）。
   - 裡面有「說明」「改動」「原始改動」三張表。「說明」記著這是從哪一版題庫做的（base_version 2026-11-02-v1）。
8. 把修改包寄給審核的人，並寫一句為什麼要改、誰決定的。

> 改動只存在這個瀏覽器分頁。**關掉分頁或斷線，沒下載的改動就不見了。** 改完馬上下載。
> 想全部重來，頁面最下面有「復原所有改動」。

### 4.2 審核的人：在「審核」頁檢查、下載套用後的題庫

1. 點分頁「審核」。
2. 左邊「修改包（Excel）」按「選擇修改包…」，選剛收到的「KIT_parent_2026-11-02_修改包.xlsx」。
3. 看右邊，由上往下：
   - 標題是加了引號的檔名：「「KIT_parent_2026-11-02_修改包.xlsx」」，下面一行「共 1 列改動，改到題庫裡 1 列。」
   - 版本：「這個修改包是從現在的題庫（2026-11-02-v1 版）做的。」
     如果寫「這個修改包是從 2026-10-30-v1 版題庫做的，現在的題庫是 2026-11-02-v1 版」，見第 8 節。
   - 「檢查套用後的題庫」：要看到綠色的「檢查通過：套用後的題庫沒有新的結構問題。」
     （如果另外寫「題庫原本就有 N 個問題，和這個修改包無關」，不用管。）
   - 「影響範圍」：「影響到：題目 1 個、題組 1 個、題本 0 個、資料檔 1 個、施測 1 個。」
     下面列出「施測：M36M084G01」「資料檔：M36M084G01-P」「題組（含這些題目所屬的題組）：P.父親親職參與」。
     題組除了修改包直接改到的，也算進改到的題目所屬的題組。
   - 「改前改後（1 列）」：表裡「表」是「題目的版本」，「哪一列」是「P.fatherinvo01n | 1」，
     「改前」「改後」只差一個句號（例如「題目：孩子父親的親職參與：……」）。
4. 左邊填四欄（會寫進改動紀錄）：
   - 「修改原因」：例如「題目文字結尾補句號，和舊題號 fatherinvo01 第 3 版一致」。**一定要填。**
   - 「誰決定的（例如：題庫小組會議）」：例如「題庫小組 2026-11-05 會議」。
   - 「誰送來的」：送修改包的人的名字。
   - 「審核人（你的名字）」：**一定要填。**
   - 修改包裡如果已經記了原因、決定者、送出者，會自動先填好，你看一下對不對。
5. 往下到「下載套用後的題庫」。
   - 還沒填好時，按鈕是灰的，旁邊寫「還差：填修改原因、審核人。」
   - 填好以後會寫「套用後題庫會從 2026-11-02-v1 版變成 2026-11-02-v2 版。zip 裡有改到的表、新的 BANK_VERSION 和這次的改動紀錄（changes/2026-11-02-v2.csv）。」
6. 按「下載套用後的題庫（zip）」。檔名像「kit_2026-11-02-v2.zip」。
   - zip 裡是一個 `kit` 資料夾：`BANK_VERSION`、`item_versions.csv`（改到的表）、`changes/2026-11-02-v2.csv`（這次的改動紀錄）。

### 4.3 交給技術人員

「技術人員」是計畫主持人指定的題庫維護者。請填上：

技術人員：＿＿＿＿＿＿（聯絡方式：＿＿＿＿＿＿）

寄給技術人員：
- 套用後的題庫 zip（例如 `kit_2026-11-02-v2.zip`）。
- 原本的修改包（留底）。
- 一句話：改了什麼、誰核准的。

技術人員會做（細節在第 9 節）：
1. 解壓縮，把 `kit` 資料夾裡的檔案放進程式碼的 `inst/extdata/kit/`，蓋掉同名檔案。
2. 跑檢查和測試，看改了什麼。
3. commit、push 到 GitHub。
4. 雲端版重新部署。部署完，雲端版題庫列的「內建題庫」會變成 2026-11-02-v2。
5. **本機版也要更新**：有在用本機版的人，請技術人員幫你重新安裝，題庫列也要顯示 2026-11-02-v2。

> **在新版題庫上線之前，不要審核下一個修改包。** app 還是舊版題庫（2026-11-02-v1），
> 審出來的 zip 會從 2026-11-02-v1 算起，兩個 zip 會互相蓋掉。
> 本機版沒更新也一樣：在舊版題庫上做的修改包、審出來的 zip 都是從舊版算起，「審核」頁會提醒「匯出以後題庫改過了」。
> 有好幾個修改包時，一次審一個，等上一個上線再審下一個；或請送件的人把改動放在同一個修改包裡。

## 5. 任務三：併入一次新施測（以 M03M048 為例）

**情境**：一次新施測的資料檔整理好了，要把它記進題庫：這次問了哪些題、哪些題換了版本、哪些是新題、哪些沒問。
以 **M03M048**（M03 世代 48 月齡，2020.03–2021.07，公開釋出編號 D00266）為例，
和它的上一次 **M03M036**（M03 世代 36 月齡）比。

> **先說一件事**：M03M048 其實已經在題庫裡了。寫「M03M048」時，左邊會出現「題庫裡已經有 M03M048 了。……要拿這次施測練習，勾上面的「練習」。」
> 要用 M03M048 練習，就勾「練習：把這次施測當成還沒進題庫（只在這個頁面試算，不會改題庫）」。
> app 會先在記憶體裡把 M03M048 從題庫的複本拿掉，再產生提案；題庫本身沒有改。
> 真正的新施測（還沒在題庫裡的代號）不用勾。
> 練習做完，可以和第 5.6 節的參考答案對照。

### 5.1 要準備哪些檔案

向資料管理的同事要：

**這次（M03M048）的資料檔**，每個 .sav 一個：

| 檔名 | 是什麼 | 在題庫裡會變成 |
|---|---|---|
| `data1.sav` | 家長問卷 | M03M048-P |
| `data2.sav` | 親友問卷 | M03M048-PK |
| `data3.sav` | 教保人員問卷 | M03M048-T |

`IRT.sav`（能力估計值）**不用上傳**：它不是題目，題庫不收。上傳了 app 也會直接刪掉、不讀。

**上一次（M03M036）的同一些資料檔**：`data1.sav`、`data2.sav`、`data3.sav`（建議一定要有）。
有上一次的檔，版本是「.sav 和 .sav 比」，比較準；沒有的話只能和題庫的文字比，比較不準。

整理檔案的方式：
- 兩次的檔名一樣，**放在兩個不同的資料夾**，例如「M03M048」和「M03M036」，不要搞混。
- 檔名要用 `data1`、`data2`、`data3`，或直接改成代號，例如 `M03M048-P.sav`。其他檔名 app 認不出來。

**用哪一版**：完整的 .sav 裡有每個人的回答，**不能傳上雲端**。
- **手上是 .sav → 用本機版**（桌面的 `run.bat`，或請技術人員開）。本機版直接上傳 .sav（上限 500 MB），只讀表頭。
- **技術人員給你 `_meta.csv` → 用雲端版也可以**。`_meta.csv` 只有變項名、標籤、值標籤（表頭），沒有任何人的回答，檔案很小。
  兩次施測各三個：`data1_meta.csv`、`data2_meta.csv`、`data3_meta.csv`（技術人員怎麼轉，見第 9.3 節）。
- 在雲端版上傳 .sav，app 會馬上刪掉、不讀，並告訴你要改用 `_meta.csv` 或本機版。

不管哪一版，app 都只用表頭（變項名、標籤、選項標籤），不讀任何人的回答；上傳的檔讀完馬上刪掉，app 不存任何檔案。

### 5.2 上傳、產生提案

1. 點分頁「併入新施測」。
2. 「新施測的代號」：打 `M03M048`。
   - 練習時（M03M048 已經在題庫裡），勾下面的「練習：把這次施測當成還沒進題庫（只在這個頁面試算，不會改題庫）」。
3. 「資料檔」按「選檔案…」，從 M03M048 資料夾**一次選好三個檔**（本機版：.sav 或 `_meta.csv`；雲端版：三個 `_meta.csv`）。
   - 一次選好幾個檔：在選檔視窗按住 **Ctrl**（Windows）或 **⌘**（Mac）再一個一個點，最後按「開啟」。
   - 雲端版的欄名是「資料檔（_meta.csv，可以多個）」，上面有一段說明為什麼不收 .sav；本機版是「資料檔（.sav 或 _meta.csv，可以多個）」。
   - 你會看到每個檔一行，例如「data1_meta.csv：N 個變項」。
4. 「上一次施測的資料檔（建議）」下面會列出要哪幾個：
   - 「M03M036-P（data1）：還沒上傳，會改和題庫的文字比（比較不準）」
   - 「M03M036-PK（data2）」「M03M036-T（data3）」同樣。
5. 「上一次施測的資料檔（建議）」按「選檔案…」，從 **M03M036 資料夾**一次選好三個檔。
   - 每一行變成「……：已上傳」。
6. 按「產生提案」。
   - 練習時，右邊最上面會寫「練習：M03M048 已經在題庫，這裡把它當成還沒進題庫來試算；題庫沒有改。」
   - 右邊標題「M03M048 的併入提案（N 列）」。
   - 下面寫每個資料檔和誰比，例如「M03M048-P：和上一次的 M03M036-P 比（用 .sav 表頭）」。
   - 再下面是各類幾列，例如「新版本：N 列（其中 N 列信心低，一定要看）」。

> 一次只能上傳一批：再按一次「選檔案…」會**取代**前一批，不是加上去。所以三個檔要一次選（上傳欄下面也有寫）。

### 5.3 提案的類別，白話說

每個變項（資料檔裡的每一欄）一列提案。「類別」的意思：

| 類別（畫面） | Excel 的「類別代碼」 | 白話 |
|---|---|---|
| 已有 | same | 這題、這一版，題庫裡已經有，一模一樣。 |
| 新版本 | new_version | 同一個變項名，但題目文字或選項改了。會建一個新的版本（例如第 3 版），舊版留著。 |
| 換題號 | renamed | 變項名不一樣，但其實是同一題（例如 `pfA06` → `pfa06n`，結尾加 n）。會建新題號，記下兩題的關係。 |
| 新題 | new_item | 題庫裡沒有、也對不到舊題的新題。 |
| 不是題目 | not_item | 系統變項、加權值、算出來的分數，不是問卷題目。照樣記進資料檔。 |
| 少問或停用 | dropped_or_block | 上一次有、這次沒有的題。整個區塊都沒有，記成「這個區塊沒問」；只少幾題、之後也沒再用的，建議標成停用；之後還有用的，只記下這次沒問。 |
| 遺漏代碼方案 | missing_scheme_change | 這個檔的遺漏代碼和上一次的不一樣，建議換方案。例如 M03M036 用 2016 方案，M03M048 用 2020 方案（多了 9995 不適用）。 |

「信心」：**高**＝可以直接接受；**中**＝建議看一下；**低**＝一定要人看。
（畫面和 Excel 都寫「高／中／低」。）

「理由」用白話寫為什麼這樣分，例如「和上一次（M03M036-P）的 .sav 表頭比：標籤和選項都一樣；用第 2 版（遺漏代碼不算）。」

### 5.4 在畫面上看提案

1. 右邊的「提案表」欄位是「提案編號」「類別」「信心」「資料檔」「變項」「題號」「理由」。
   已經排好：**信心低的在最前面，「已有」在最後面**。從上面往下看。
2. 「提案編號」（p0001、p0002……）和下載的 Excel 的「提案編號」欄一樣，用它對照畫面和 Excel。
3. 點提案表的一列，會跳到「題項查詢」，打開那一題，看它以前各波次怎麼問、有哪些版本。
   看完點分頁「併入新施測」回來，提案還在。
4. 表格上方的搜尋框可以找變項名，例如打 `fameviC16`。
5. 也可以用「比較」頁看兩次施測的差異（第 6.4 節）。例如 M03M036-P 和 M03M048-P：
   只在 A 24 處、只在 B 9 處、換題號 6 處、位置不同 7 處、選項不同 5 處、遺漏代碼不同 1 處。

### 5.5 下載提案 Excel、填「決定」

1. 按「下載併入提案（Excel）」，得到「併入提案_M03M048_日期.xlsx」，三張表：
   - 「說明」：每一類是什麼、信心的意思、「決定」欄怎麼填。
   - 「統計」：「類別代碼」「類別」「信心高」「信心中」「信心低」「合計」。
   - 「提案」：一列一個提案，和畫面上的提案表同一批。

2. **對照畫面和 Excel**：用「提案編號」（例如 p0123）最準；或用「資料檔」＋「變項」兩欄一起對（同一個變項名在不同資料檔會各有一列）。
   Excel 裡**先用「信心」欄篩選 low**（就是畫面上的「低」），這些一定要看；再看 medium。

3. **「提案」表的欄位**（畫面上沒有的，一欄一句話）：

   | 欄 | 意思 |
   |---|---|
   | 編號 | 提案的編號，和畫面一樣（p0001…）。 |
   | 類別代碼、類別 | 見第 5.3 節的表。 |
   | 動作 | 只有「少問或停用」會填：block_none＝整個區塊沒問、block_subset＝區塊只問一部分、deprecate＝建議停用、not_asked＝只記下這次沒問。 |
   | 資料檔、變項、順序 | 新施測的哪個資料檔、哪個變項、在檔裡第幾欄。 |
   | 種類 | 這個變項是什麼：item＝題目、system＝系統變項、weight＝權重、derived＝算出來的變項。 |
   | 題號位置 | 問卷上印的題號，例如「四」「二.5」（從 .sav 標籤前面讀出來的）。 |
   | 題目代碼、版本 | 這個變項在題庫裡會是哪一題、第幾版，例如 `P.fameviC16`、3。**Excel 的「題目代碼」就是畫面上的「題號」。** |
   | 原題目代碼、原版本 | 「新版本」「換題號」才有：它是從哪一題、哪一版來的。 |
   | 區塊 | 題目所在的問卷段落。 |
   | 標籤相似度 | 題目文字和上一次比有多像：identical＝一模一樣、high＝幾乎一樣、medium＝有點不同、low＝很不同；空白＝沒有可比的。 |
   | 選項相同 | 選項和上一次比：same＝一樣、codes_differ＝選項代碼不同、labels_differ＝代碼一樣但選項文字不同、unknown＝沒有可比的。（遺漏代碼不算。） |
   | 遺漏代碼方案 | 「遺漏代碼方案」那一類才有：建議改用哪一套（2016 或 2020）。 |
   | 上一次的資料檔 | 這一列是和哪一個資料檔比的，例如 M03M036-P。 |
   | 標籤、選項 | 新施測 .sav 裡的題目標籤、選項。 |
   | 信心、理由 | 和畫面一樣。 |
   | 決定（接受／不接受／再討論） | 最後一欄，空白，給你填。 |

4. **填「決定」**：每一列填「接受」「不接受」或「再討論」。

   **你可以自己決定的**（直接填「接受」）：
   - 「已有」。
   - 「不是題目」。
   - 信心「高」的「遺漏代碼方案」。

   **要先問人、不能自己決定的**（先填「再討論」，問完再改）：
   - 所有信心「低」的列。
   - 「新版本」「換題號」「新題」：是不是同一題、文字改得算不算新版本，問負責的老師。
   - 「少問或停用」：是故意拿掉還是檔案漏了，問統計人員（或負責資料的同事）。
   - 信心不是「高」的「遺漏代碼方案」：問統計人員。

   **只差標點或空白的「新版本」**：不要建新版本，沿用舊版本。填「不接受」，並在同一格寫要用哪一版，
   例如「不接受（用第 2 版）」。（Excel 沒有另外的備註欄，就寫在「決定」這一格。）
   版本號看「原版本」欄。

   全部看完都同意，也可以在「說明」表寫一句「全部接受」。

5. 把填好的 Excel，和 `_meta.csv`（或 .sav）交給技術人員。練習時不用交。

幾列代表性的提案和怎麼決定：

- **新版本：`fameviC16`（家長）**。題目文字比上一次多了「或照顧孩子的環境」，「標籤相似度」不是 identical。

## 6. 各頁說明

### 6.1 題項查詢

用關鍵字、波次、構面找題目，看一題在各波次怎麼問。

- 「關鍵字」：多個詞用空白分開。不分全形半形、簡體繁體。找題號開頭時加 `*`，例如 `sle*`、`fatherinvo01*`。
  - 「每個詞都要有」／「任一個詞」。
  - 「找」：「題目文字」（預設）或「全部欄位」。
- 「波次」：可以選好幾個；打代號或白話都找得到，例如 `M36M084G01`、`84M`、`G01`、「小一」、「國小一年級」、`M036大`。
  - 「任一波次」／「每個波次都有」。
- 「構面」（就是題組）：可以選好幾個。「任一構面」／「每個構面都有」。
- 「進階設定（區塊、題型、填答者）」：「區塊」是問卷的段落；另有「題型」「填答者」「包含已停用的題目」。
- 「清除條件」：全部重來。

右邊：
- 「本次：……」一行寫現在的條件。
- 結果一句話，例如「共 1,533 題（不含 528 題已停用）……」。
- 「下載查詢結果」：Excel，含跨波次對照表和說明。
- 點一列 →「這一題：……」：題目、選項、不作答代碼、出現的波次、構面；有「各版本差在哪」「同一個題幹的其他題」「! 要注意」。
  - 「改這一題 →」：到「題庫編修」改這一題。
  - 「下載沿革單（Word）」：這一題家族（含換題號）的各版本、用在哪些施測、版本之間的關係、屬於哪些題組。
- 從別的頁跳過來時，會出現「← 回到剛才的查詢」。
- 頁面下方可以點開「跨波次對照表」「各波次題數」（熱圖）。
- 0 題時會告訴你為什麼、可以試什麼，並列出名稱有這個詞的構面。

### 6.2 構面查詢

看一個題組有哪些題、各波次信度、網路圖，產生構面報告。只看不改。

- 左邊「構面」：搜尋名稱或別名。「波次（構面報告用）」：做報告時才要選。
- 沒選構面：右邊是「構面清單」，點一列就選它。
- 選了構面：
  - 「回到構面清單」「下載各波次題目表（Excel）」「改這個構面 →」（到題庫編修改這個構面）。
  - 標題下面：主要名稱只顯示一個，其他叫法列在「別名（搜尋也找得到）」。
  - 「題組資訊：概念、官方文件、文獻」：
    - 概念、英文名稱、領域（領域照官方《問卷構面及信效度》：認知發展、語言發展、社會情緒發展、身體動作發展、家庭，加上教保／學校環境、健康、兒童福祉與適應、學習、基本資料、調查管理）。
    - 「同一概念的家長、教師、兒童版本」：例如「社會能力」有家長評、教師評、兒童自評三個題組。**不同填答者的分數分開計分，不能直接相加或比較。**
    - 「官方文件」：這個題組在《3-24月齡／36-72月齡／G1-G3 問卷構面及信效度》裡的官方名稱（中英）、信效度。
    - 「文獻」：量表出處、中文版修訂、KIT 自己的編製驗證、效標工具；每一筆標「已在 PubMed 核對」「取自 KIT 文件」或「可能的出處（未確認）」。
  - 「題目 × 波次（縱貫比較用）」：每一格是那一波問的版本（v1、v2…），M03、M36 分開；★ 錨題是這個世代每一波都問、而且版本相同的題，可以當縱貫比較的共同題。
  - 題目 × 波次表：點一題，到「題項查詢」看細節。
  - 「用關鍵字可能找到更多 →」：這裡只列已歸到這個構面的題，用名稱當關鍵字可能找到還沒歸類的。
  - 「和其他構面共用的題目」「題組沿革」「各波次信度」「網路圖」（勾「也畫這些題目的其他構面」可以看相關題組）。
- 「產生構面報告」→「下載 Word」「下載 HTML」。
- 上層題組（例如「社會能力」）自己沒有題目：會列出它的子題組，點名字就換過去；下載的各波次題目表會放全部子題組的題目。見第 3.1 節。

### 6.3 施測

選一次施測，看它的資料檔、變項清單、哪些區塊沒問；下載 codebook。只看不改。

1. 左邊「施測」搜尋：代號或別名都可以，例如 `M36M084G01`、`M036大`、`M36W84`、`D00250`、`84M`。
   或在右邊「施測清單」點一列（欄位：施測、代號、狀態、資料檔、題數）。狀態「內部」表示還沒公開釋出。
2. 右邊概要：調查期間、狀態（已釋出時附公開釋出編號）、資料檔、遺漏代碼、區塊狀態、建議引用。
   例：M03M048「M03 世代 48 月齡（2020.03–2021.07）」，已釋出，D00266，4 個資料檔。
3. 「資料檔」選一個（家長、親友、教保人員……），表格依問卷順序列出變項：位置、變項、題目、區塊、題組。
   標「［公開檔沒有］」的變項，調查有問但公開檔沒有。點一題到「題項查詢」。
4. 下載：
   - 「下載施測題目清單（Excel）」：整次施測的 codebook，一個資料檔一張表，第一張是說明。
   - 「下載 SPSS 標籤（家長）」等：SPSS 語法檔 `.sps`，加上變項標籤、選項標籤、遺漏值。只做目前選的資料檔、只放公開檔有的變項。
     在 SPSS 開好資料檔後，打開這個 .sps 執行即可。
   - 「下載 DDI 編碼簿（XML）」：給資料庫或典藏單位用的國際標準格式。
   - 「下載題庫結構（datapackage.json）」：給技術人員。

### 6.4 比較

選兩個資料檔，只列出不一樣的地方。

1. 「資料檔 A」「資料檔 B」：搜尋代號、施測或填答者。例如 A 選 M03M036-P、B 選 M03M048-P。「A、B 對調」可以交換。
2. 「要看的差異」可以只勾想看的：「只在 A」「只在 B」「換題號」「版本不同」「位置不同」「選項不同」「遺漏代碼不同」。
3. 右邊「差異（N 處）」和「差異表」（差異、變項、題目、A、B）。點一列到「題項查詢」。
4. 「下載差異清單（Excel）」。

### 6.5 待辦事項

題庫裡要注意的地方，依「誰能處理」分成四堆：自己能改、要問老師、要問統計人員、要請技術人員改。點一筆，會打開能看它的分頁。每種最多列 20 筆，全部的請按「下載要注意的完整清單（Excel）」（一個處理人一張表）。

這一頁看的是**三個題庫合在一起**（家長、兒童青少年、教保人員），不管題庫列選哪一個（畫面上也有寫）。2026-11-02-v1 共 349 筆：

**自己能改（64）**——看題庫就能改，到「題庫編修」改，走修改包 → 審核。
- 「題組沒有任何題目」（37）：例如 P.HOME量表。請確認要不要刪，或請老師放題目。
- 「簡體字」（2）：例如 `P.med0303` 題目有「髋」，應為「髖」；`T.T51010n` 有「内」，應為「內」。
- 「文字有換行」（25）：例如 `P.med0801`。把換行拿掉。

**要問老師（220）**——要懂題目內容才能判斷。把清單整理給負責的老師，老師決定後，由你在「題庫編修」改，或請老師用「改版」。
- 「換題號後的新題沒有接上題組」（45）：例如舊題 `P.fameviD1101` 在題組「3C產品環境」，新題 `P.fameviD1101n` 沒有題組。
- 「題組只有 1 題」（158）。
- 「題目掛在中間層題組」（17）：例如兒童 4–6 年級「學校環境」直接掛了 18 題。

**要問統計人員（5）**——要看資料檔才能判斷。把清單轉給統計人員。
- 「同一題本、同一年度的資料檔題目不同」（4）。
- 「內部施測的資料檔（v02）」（1）：25 個資料檔還沒有 .sav。

**要請技術人員改（60）**——app 裡沒有頁面能改的欄位。把清單轉給技術人員。
- 「題目的角色或模組空白」（60）：例如 `C.CelderE01`。題目的 role、module 兩欄 app 改不到，要技術人員直接改題庫的表。

> 有兩種檢查要對照 .sav 表頭，這一頁不做；畫面上有寫，請維護者在自己電腦上跑。

### 6.6 題庫編修

全 app 唯一能改題庫的地方。改好以後下載「修改包」，送去「審核」。

「要改什麼」三選一：
- **「題目內容」**：上面有「要注意」表（可用「看哪一種」篩選，點一列就帶入那一題）；或在「題目（itemID）」選一題、在「版本」選一版。
  可以改「題目文字（label）」「選項（value）」「遺漏值（noResponse）」「反向計分（reverseScored）」「題型（itemType）」「填答者（respondent）」「停用（deprecated）」「備註（note）」，
  以及「區塊、題幹」裡的「區塊（block）」「題幹（stemID）」。改完一定要按「套用這一題的改動」。
- **「題目的構面」**：選一個構面（或用「新增構面」建一個），在右邊表點題目：點一下勾選，再點一下取消。
  有「只看已勾的」「勾選目前篩出的全部」「取消目前篩出的全部」「刪除這個構面」。
- **「構面資訊（名稱、別名、信度）」**：改名稱、別名、備註、「信度（全部波次）」，按「套用」；某一波次的信度用「設定這個波次的信度」。

這裡**不能改「這一題在哪一波有問」**：0.3 的施測內容以 .sav 為準，由「併入新施測」記進題庫。
覺得某一題的波次記錯了，請告訴技術人員。

下面：
- 「本次改動：……」一行摘要；「改了哪些」可以點開看明細。
- 「下載修改包」：還沒有改動時是灰的，旁邊寫「還差：還沒有改動。」
- 「復原所有改動」：丟掉這個題庫的所有改動（會再問一次）。
- 三個題庫各自記自己的改動，切換題庫不會弄丟；但關掉分頁就沒了。

### 6.7 改版（老師改題本）

題本要出下一版時：給老師一份改版底稿，老師填好交回，先做健康檢查，再變成修改包。

**例子**：家長國小 4–6 年級題本要為 M03 世代小五（132 月齡）改版。

**① 下載改版底稿**
1. 點「改版」。「題本」選「家長 國小 4–6 年級（P-G4-G6）」。
2. 會寫「根據 M03 世代 120 月齡・小四（內部） 的家長問卷，558 題。」——底稿是這個題本**最近一次施測**的題目，照問卷順序。
3. 按「下載改版底稿（Excel）」，得到「改版底稿_P-G4-G6_日期.xlsx」，交給老師。

**老師要填什麼**（底稿的「說明」表也有寫）：
- 「題目」表：一題一列。灰色欄（列號、位置、變項、目前題目、目前選項）不要改；黃色欄給老師填。
- 「動作」用下拉選單選：「不變」「改文字」「改選項」「刪除」。沒選就當作不變。
  - 改文字：在「新題目文字」寫改好的**整句**。例如 Q535 `socD09`「這孩子會做一些讓別人感到開心或覺得溫暖的事情。」要改，動作選「改文字」，新題目文字寫整句新句子。
  - 改選項：在「新選項」照「1=有; 2=沒有」的寫法寫**全部**選項。
  - 刪除：新的問卷不放這題（題庫會留著舊題）。
- 「新增題目」表：一題一列，「變項名稱」「題目文字」「放在哪一列之後」一定要填（寫「題目」表的列號，例如 Q012；放最前面寫「開頭」），另有「選項」「區塊」「備註」。
- 不要刪列、加列、改列號、刪欄、改欄名。

**② 上傳填好的底稿**
1. 「② 上傳填好的底稿」按「選檔案…」，選老師交回的檔。
2. 右邊「健康檢查」：
   - 有「擋下來」：「有 N 個問題要先改好（擋下來），才能變成修改包。請老師改好底稿再傳一次。」
     表格的「位置」告訴你哪一張表第幾列。常見原因：選了「改文字」但「新題目文字」是空的；選項寫法看不懂；列號被改過或少了列；新題目的變項名稱重複、已被用過、不是英文字母開頭；「放在哪一列之後」寫錯；底稿太舊（題庫已經沒有那個資料檔）。
     **處理**：把表格內容告訴老師，請老師改好再傳。
   - 只有「要注意」：「沒有擋下來的問題。有 N 個地方要注意，請看一下。」
     常見：寫了新文字但動作是「不變」（不會用到）；新文字和原本一樣（不會產生新版本）；新題沒有選項（當成開放題）；底稿是舊版題庫做的；新施測的月齡不在題本範圍內。
     **處理**：看過、確認沒問題就可以繼續；有疑問問老師。
3. 左邊「新施測的代號」寫新代號，例如 `M03M132G05`（M03 世代、132 月齡、小五）。
   - 寫法：世代代號 + M + 三位數月齡；84 月齡以後再加 G 和兩位數年級。要用**還沒有**的代號。
4. 右邊「修改包」會寫「規劃中的施測 M03M132G05，資料檔 M03M132G05-P（根據 M03M120G04-P）：」，列出不變幾題、改文字幾題、改選項幾題、刪除幾題、新增幾題。
5. 按「下載修改包（Excel）」，得到「修改包_改版_M03M132G05_日期.xlsx」。
6. 把這個修改包拿到「審核」頁，照第 4.2 節做。
   （影響範圍會很大，例如題目 564 個，因為新施測的每一題都要記進新資料檔，這是正常的。）

- 任何人數是 1 到 4 人時，寫成「<5」，不寫真正的數字（0 照寫）。
- 一題的有效人數少於 10 人時，不列平均數、標準差和百分位數。

## 7. 名詞解釋

**波次**：一次施測。畫面上「波次」「施測」說的是同一件事，例如「M36M084G01」這一波就是 M36 世代 84 月齡那一次施測。

**施測代號（adminID）**：一次施測的代號。例如 `M36M084G01`：
- `M36`：世代。M36 是 36 個月大時開始追蹤的那一群孩子；`M03` 是 3 個月大開始追蹤的。
- `M084`：這次施測時孩子 84 個月大。
- `G01`：國小一年級（84 月齡以後才有；`G07` 是國一）。
- 畫面上會附白話，例如「M36M084G01 · 84 個月・小一（M36 世代）」。

**別名**：同一次施測的其他叫法，搜尋時都找得到。例如 M36M084G01 也可以打 `84M`、`84月齡`、`G01`、`國小一年級`、`國小1年級`、`小一`、`M084大`、`M36W84`、`D00250`、`36月齡組84月齡`。
注意：`84M`、`G01`、「小一」這種說法兩個世代都有（M03M084G01 和 M36M084G01），會一起找到。

**題號（item_uid）**：一題在題庫裡的身分證，例如 `P.fatherinvo01`。
- 前面的字母是問卷別：`P` 家長、`C` 兒童青少年、`T` 教師／教保人員。
- 後面是 SPSS 裡的變項名。「題項查詢」「題庫編修」只顯示後面那段（itemID，例如 `fatherinvo01`）。
- **版本（itemVer）**：同一題的文字或選項改過，就是新的一版（第 1 版、第 2 版……），舊版留著。
- **換題號**：同一題換了變項名，例如 `fatherinvo01` → `fatherinvo01n`（從 M36M084G01 開始）。題庫會記下兩題的關係。

**題組**：一組一起計分、測同一個概念的題目，例如「利社會行為」。題組可以有上下層（「社會情緒」→「社會能力」→「利社會行為」）。
在「構面查詢」和「題項查詢」的「構面」選單裡叫「構面」。

**區塊**：問卷裡的一個段落，例如「家庭問卷資料_親職參與」「社會情緒問卷資料」。
在「題項查詢」表格叫 `block`，進階設定、題目細節和「題庫編修」都叫「區塊」；「施測」頁的變項表也有「區塊」欄（旁邊的「題組」欄才是題組）。
「區塊狀態」記的是某次施測某個區塊「沒問」或「只問一部分」。

**題本（form）**：一份問卷的版本範圍，例如「家長 國小 1–3 年級（P-G1-G3）」「教保 學前（T-presch）」。

**資料檔（dataset）**：一次施測的一個檔，例如 `M03M048-P`（家長，data1）、`-PK`（親友，data2）、`-T`（教保人員，data3）、`-C`（兒童）。IRT 能力估計值檔不收進題庫。

**遺漏代碼**：沒有有效答案時填的數字，分析前要設成遺漏值。有兩套：

| 代碼 | 2016 方案 | 2020 方案 |
|---|---|---|
| 7777 | 拒答 | 拒答 |
| 8888 | 不知道 | 不知道 |
| 9995 | （沒有） | 不適用 |
| 9996 | 跳答或不適用 | 跳答 |
| 9999 | 遺漏值 | 遺漏值 |

例如 M03M036 用 2016 方案，M03M048 用 2020 方案。「施測」頁的概要會寫這次用哪一套；SPSS 標籤會自動設好。

**修改包**：記著「改了什麼」的 Excel（不是整份題庫）。從「題庫編修」或「改版」下載，拿到「審核」檢查。
檔名像「KIT_parent_2026-11-02_修改包.xlsx」或「修改包_改版_M03M132G05_20261102.xlsx」。

**題庫版本**：例如 `2026-11-02-v1`，寫在題庫列「內建題庫 2026-11-02-v1」。前面是做出這版題庫的日期，後面是當天第幾版。
同一天再審核下載一次就是 `2026-11-02-v2`；換一天從 `v1` 開始（例如 `2026-11-05-v1`）。套用後題庫的 zip 也用這個名字，例如 `kit_2026-11-02-v1.zip`。

**結構問題**：題庫的表之間對不起來的地方，例如某一列指到一個不存在的題目、同一個題號出現兩次、必填的欄是空的。
「審核」頁會在套用修改包以後檢查；修改包造成**新的**結構問題就不能下載，要請送件人改好。題庫原本就有的問題不擋。

**題組 Excel 裡的英文欄名**（「下載各波次題目表（Excel）」的「題目」表）：
`itemID` = 題號（變項名）、`itemVer` = 版本、`deprecated` = 停用（1 是已經不用的舊版本）、
`respondent` = 填答者、`label` = 題目文字。

**改動紀錄**：每一版一個檔 `changes/2026-11-02-v1.csv`，記每一格改前、改後、原因、誰決定、誰送、誰審核。

**併入提案**：「併入新施測」產生的清單，每個變項一列，說它該怎麼進題庫。

## 8. 常見問題與排除

**Q：「併入新施測」上傳 .sav，寫「雲端版不收 .sav」。**
雲端版為了保護個資，不收完整的 .sav（檔案已經刪掉、沒有讀）。請技術人員轉成 `_meta.csv`（第 9.3 節）再上傳，或改用本機版（桌面的 `run.bat`，或請技術人員開）。

**Q：本機版上傳 .sav 時失敗，或寫「Maximum upload size exceeded」。**
本機版上限 500 MB。還是太大時，把 .sav 轉成 `_meta.csv`（第 9.3 節）再上傳。

**Q：「審核」頁說「這個修改包是從 2026-10-30-v1 版題庫做的，現在的題庫是 2026-11-02-v1 版：匯出以後題庫改過了。」**
修改包是在舊版題庫上做的（例如送件人用的本機版還沒更新，或在新版上線前做的）。
1. 仔細看「改前改後」的「改前」是不是送件人當時看到的樣子。
2. 有「這些格子在修改包匯出以後被改過」：表示別人也改了同一格，確認要不要蓋掉。
3. 有「套不上的改動」：請送件人在新版題庫上重做。
4. 都沒問題可以照常下載。
「沒有記下是從哪一版題庫做的」的修改包，也照這個方式檢查。

**Q：畫面變灰，寫「Disconnected from the server」。**
和伺服器的連線斷了（閒置太久、網路不穩，或程式出錯）。
1. 重新整理頁面（F5）。
2. 「題庫編修」裡**沒下載的改動會不見**，要重做。所以改完就下載修改包。
3. 同一個動作一再斷線，記下你按了什麼（哪一頁、哪一題），告訴技術人員。

**Q：「構面查詢」選「社會能力」沒有題目表。**
「社會能力」是上層題組，題目在下層。畫面會列出子題組，點名字就換過去；下載的各波次題目表會放全部子題組的題目。見第 3.1 節。

**Q：「併入新施測」寫「題庫裡已經有 M03M048 了」。**
這次施測已經在題庫裡了，不能再併一次。確認代號有沒有打錯。要拿它練習，勾「練習：把這次施測當成還沒進題庫……」。

**Q：「併入新施測」說「認不出這些檔是哪一個資料檔」。**
檔名要是 `data1`、`data2`、`data3`（可以加 `_meta`；IRT 檔不用傳），或 `M03M048-P` 這種代號。改檔名再上傳。

**Q：「改版」寫「施測代號 M03M108G03 已經有了」或「寫法不對」。**
新施測要用還沒有的代號，寫法像 `M03M132G05`（84 月齡以後要加 G 和兩位數年級，以前不加）。

**Q：「審核」的下載按鈕是灰的。**
看按鈕上方「還差：」寫什麼。通常是還沒填「修改原因」或「審核人」；或修改包有套不上的改動、新的結構問題。

**Q：審核完了，app 上還是舊的內容。**
正常。要等技術人員放進程式碼、雲端重新部署，題庫列才會變成新版本（例如 2026-11-02-v2）。部署前不要審下一個修改包。

**Q：雲端版已經是 2026-11-02-v2，本機版還是 2026-11-02-v1。**
本機版不會自己更新。請技術人員幫你重新安裝，題庫列顯示 2026-11-02-v2 以後再用本機版做修改包或審核；
不然修改包是在舊題庫上做的，「審核」頁會提醒「匯出以後題庫改過了」。

**Q：下載了修改包，想接著改。**
「打開題庫 Excel…」只能打開 0.2 格式的整份題庫，不能打開修改包。要接著改，請在同一個瀏覽器分頁繼續改，再下載一個新的修改包（它會包含全部改動）。改好的修改包交給審核的人，在「審核」頁上傳。

**Q：查不到某一題。**
- 試「全部欄位」、換成「任一個詞」、打題號開頭加 `*`。
- 打開「進階設定」勾「包含已停用的題目」。
- 確認題庫列選對了（家長／兒童青少年／教保人員）。

## 9. 給技術人員（含 R 程式碼）

以下需要 R 和 kitItemBank 的原始碼（repo `jiewenTsai/kitItmBank`）。在 repo 根目錄執行。

### 9.1 開本機版

```r
# install.packages("pak")
pak::pkg_install("jiewenTsai/kitItmBank")
kitItemBank::run_kititembank()   # 本機版：有「統計」頁，上傳上限 500 MB
```

開發時：

```bash
LC_ALL=en_US.UTF-8 Rscript --no-init-file -e 'pkgload::load_all(); run_kititembank()'
```

### 9.2 收到「套用後的題庫」zip

zip 裡是 `kit/` 資料夾（`BANK_VERSION`、改到的表、`changes/<新版本>.csv`）。

```r
utils::unzip("kit_2026-11-02-v1.zip", exdir = "inst/extdata")   # 蓋掉 inst/extdata/kit/ 的同名檔
pkgload::load_all()
kitItemBank::check_kit(kitItemBank::read_kit())                    # 0 列 = 沒問題
devtools::test()
```

```bash
git diff --stat inst/extdata/kit
git diff inst/extdata/kit
git add inst/extdata/kit
git commit -m "題庫 2026-11-02-v2：fatherinvo01n 題目補句號"
git push
```

然後在 Posit Connect Cloud 重新部署（用根目錄的 `app.R` 和 `manifest.json`；有新套件時先更新 `manifest.json`）。
部署後確認題庫列顯示新版本，再通知審核的同事可以審下一個修改包。

也可以不經 app，直接讀修改包審核：

```r
pkg <- kitItemBank::read_review_package("KIT_parent_2026-11-02_修改包.xlsx")
rv  <- kitItemBank::review_patch(kitItemBank::read_kit(), pkg$patch, pkg$base_version)
rv$blocking   # 空的 = 可以套用
```

### 9.3 把 .sav 轉成 `_meta.csv`（雲端版要用，或檔案太大時）

雲端版的「併入新施測」只收 `_meta.csv`。在自己電腦轉：只讀表頭（變項名、標籤、值標籤），不讀任何人的資料。需要 haven 套件。

```r
# install.packages("haven")
for (f in c("data1", "data2", "data3")) {
  m <- kitItemBank::sav_header_meta(file.path("M03M048", paste0(f, ".sav")))
  readr::write_csv(m, file.path("M03M048", paste0(f, "_meta.csv")))
}
# 上一次（M03M036）照樣做一份，放在 M03M036 資料夾
```

### 9.4 照提案把新施測寫進題庫

```r
kit  <- kitItemBank::read_kit()
meta <- list("M03M048-P"  = kitItemBank::sav_header_meta("M03M048/data1.sav"),
             "M03M048-PK" = kitItemBank::sav_header_meta("M03M048/data2.sav"),
             "M03M048-T"  = kitItemBank::sav_header_meta("M03M048/data3.sav"))
prev <- list("M03M036-P"  = kitItemBank::sav_header_meta("M03M036/data1.sav"),
             "M03M036-PK" = kitItemBank::sav_header_meta("M03M036/data2.sav"),
             "M03M036-T"  = kitItemBank::sav_header_meta("M03M036/data3.sav"))
p <- kitItemBank::propose_admin_merge(kit, meta, "M03M048", prev_meta = prev)
kitItemBank::admin_merge_summary(p)

# 照同事在提案 Excel「決定」欄接受的 proposal_id（或 TRUE = 全部、或 "high" = 高信心的全部）
ok   <- c("p0001", "p0002")            # 換成實際接受的
kit2 <- kitItemBank::apply_admin_merge(kit, p, accept = ok)
kitItemBank::check_kit(kit2)
kitItemBank::write_kit(kit2, "inst/extdata/kit")
```

之後照 9.2 的 `git diff`、測試、commit、push、重新部署。`BANK_VERSION` 記得往上加（`kitItemBank::bump_bank_version()`）。

**練習用（M03M048 已經在題庫裡）**：app 的「練習」勾選框做的就是這件事。不經 app 時，
